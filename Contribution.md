## Contributing

Contributions are always welcome! If you found a bug or have an idea for a feature, feel free to open an Issue.

### Reporting Bugs
If you encounter a bug, please [open an Issue](https://github.com/Dua-DSL/Dua-Domain-Specific-Language-Engine/issues/new) and include:
* **Description**: A clear summary of the issue.
* **How to reproduce**: A small code snippet or simple steps showing where and how the error happens.
* **Environment**: Your Lua version (e.g., Lua 5.1, LuaJIT).

---

### Feature Requests
When suggesting a new feature, please provide a clear rationale to help evaluate it. Consider including:
1. **Use Cases**: Describe how and where this feature would be used.
2. **Alternatives**: Are there existing ways to achieve this? How does your proposed feature improve upon them?
3. **Side Effects & Implications**: Potential impacts on performance, sandboxing security, or API backwards compatibility.
4. **Mockups / Syntax Examples**: Screenshots or code snippets showing how the syntax or output should look.
5. **Implementation Sketch**: A brief draft or idea of how this could be implemented (if applicable).
